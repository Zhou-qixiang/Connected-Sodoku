# 连通数独（Connected Sudoku）

一个单文件 HTML/CSS/JS 的连通数独网页游戏。

## 如何运行

直接用浏览器打开 `connected-sudoku.html` 即可，无需安装任何依赖。

> 推荐 Chrome / Edge / Firefox 等现代浏览器。

## 游戏规则

整个棋盘是一个 **14×14** 的全局网格，但只有中间十字形的四个 **6×6** 子区域是有效格子，四个角被隐藏。

四个子数独按如下坐标固定拼接：

| 区域 | 全局坐标 | 规则 |
|------|----------|------|
| 奇偶数独 | 行 0–5，列 4–9 | 白点两侧的数字必须一奇一偶 |
| 彩色数独 | 行 4–9，列 0–5 | 每个 2×2 同色块内数字不能重复 |
| 差值数独 | 行 4–9，列 8–13 | 圆圈两侧数字之差等于圆圈内数字 |
| 箭头数独 | 行 8–13，列 4–9 | 每个 2×2 块有唯一最大数，箭头指向它 |

相邻两个子数独只在 **2×2** 的角落处重叠。

## 通用约束

- 每个 6×6 子区域里，每行、每列都必须包含 1–6 且不重复。
- 所有提示数字和线索都已根据一个统一的基准解生成。
- 当前关卡设计允许存在多个解，但保证可玩且结构合法。

## 操作说明

- **鼠标 / 触屏**：点击格子选中，再点击数字键输入。
- **键盘**：数字键 `1–6` 输入，`Backspace / Delete` 擦除，方向键移动选框。
- **显示冲突**：开启后会实时标红违反规则的格子。
- **检查答案**：一键高亮当前所有冲突。
- **清除填写**：清空所有非提示数字。
- **重新开始**：重置本关计时和填数。

## 关卡

共 15 关，分为：

- **简单**（5 关）：较多提示，适合熟悉规则。
- **中等**（5 关）：减少提示，需要跨区域联动推理。
- **困难**（5 关）：提示最少，需要长推理链。

## 技术说明

- 游戏完全自包含，没有外部资源、没有后端。
- 棋盘渲染、线索绘制、冲突检测、计时器和胜利弹窗全部在同一文件内实现。
- 关卡数据基于固定坐标模板生成，支持 5 种保持奇偶性的数值置换，保证不同关卡之间结构一致。

## 本地验证

如果想校验关卡数据，可以临时把 HTML 中 `<script>` 里的核心逻辑复制到 Node.js 环境中执行，内置的 `validateLevelData()` 和 `countSolutions()` 会检查每一关的结构合法性与可解性。
